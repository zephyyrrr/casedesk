Case Desk – Privacy policy

Last updated: 23 October 2026

Case Desk is a private assistant used by a single household. It is not offered to the public, and only the owners of the connected Google account use it.

What data it accesses

With the account owner's permission, Case Desk reads messages in the owner's Gmail account (read-only), and it can save email drafts in that account. It never sends email and never deletes or changes existing messages.

How the data is used

Data is used only to answer the account owner's own requests, such as finding a message or preparing a draft. It is not sold, shared, used for advertising, or used to train AI models.

Storage

Data is processed on the owner's own computer and stored there in encrypted form.

Google API Services

Case Desk's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The account owner can withdraw access at any time at myaccount.google.com/permissions.

Contact

Questions can be sent to the support email shown on the Google sign-in screen for Case Desk.
